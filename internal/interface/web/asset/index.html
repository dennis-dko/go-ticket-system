        Maintenance mode
        
        
        Turns everyone else away with a notice while the installation stays running. Use it before restoring or moving the database: what is written during that window is lost when the snapshot goes back, and whoever wrote it has no way to know.
        
        
        While it is on, only people who may administer this installation can work: this built-in account and anyone holding the administrator role. Everyone else is turned away — that is the point.

        Push notifications
        
        
        What somebody is told about their tickets - a customer's answer, a ticket handed to them, a deadline running out - is pushed to the browsers they switch it on for under My account, even while no page is open. Each push leaves through the push service of the browser's maker: Google's for Chrome, Mozilla's for Firefox, Apple's for Safari. It is encrypted for that browser alone, so the push service carries it without reading it - but it learns that this installation sent something, and when.
        
        
        
          
        
        
        
      
        

      
        
        
        Operation and limits
        
        
        Leave a field empty to keep the value from the configuration file. Changes take effect within a few seconds, without a restart - except the session lifetime, which applies from the next sign-in.
        
        
        
          
          
          
          
          
          
        
        
        
        The deletion limit is a share of the directory accounts already here. With one or two of them, a single departure is all or half of them, so a limit below that refuses it: raise it for that run if the departure is real.

        Logging, metrics and tracing
        
        
        
        
        The log level applies at once. The metrics port is bound and the trace exporter is built while the application starts, so those are saved here and applied the next time it starts; the restart card lists what is waiting. A field left following the configuration file keeps its value from there.
        
        
        The metrics port asks for no sign-in, is not covered by TLS, and serves Go's profiling endpoints beside the metrics — anywhere it is reachable, so is a heap dump. Expose it to your monitoring only.

        Directory synchronisation
        
        
        Reconciles the users with the directory. LDAP is only ever read, never changed.
        
        
        Careful: accounts missing from the directory are deleted here, together with their tokens and sessions, and the tickets they owned are left without an owner. This cannot be undone. Always run the preview first.
        

        
        
          
        
            
          
        
          
        Empty by default, and worth leaving empty until a preview has been read: an automatic run deletes without anybody looking. Applied at the next start — the scheduler is built while the application starts. It runs on the server's clock, which is UTC in the container this application ships, and not in the instance timezone.

        Sign-in provider (OpenID Connect)
        
        
        People can sign in through your organisation’s provider – Keycloak, Authentik, Entra ID, Google – instead of with a password, once each of them has linked their account to it under My account. Nobody is signed in by an address alone, and no account is ever made for somebody the provider knows. Register this installation at the provider with the address below to send people back to.
